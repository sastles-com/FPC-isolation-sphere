> **プロジェクトの出発点（動機）**: 「デジタル地球儀を作る」ことではない。
> **コンタクトジャグリングのクリスタルボールを、光って映像を映せるガジェットにする**のが目的。
> 「球体ディスプレイ / デジタル地球儀」はその技術的な実現形にすぎない。
> この動機（＝毎回落とすプロップ）が「壊れても直せる＝接着剤ゼロ・カセット交換式」という設計原理に直結する。記事では**動機を取り違えない**こと。

  **FPCベースV2 = プロジェクトの到達点・最終形**を提示する**決定版ドキュメント**。
- 過去世代は「ここに至る道」として軽く参照リンクするだけ（詳細は再説明しない＝前提）。
- **編集スタンス = 「設計の最終形（design vision）」**:
  - 確定した設計判断は最終形として自信を持って提示（却下案・迷いは列挙しない）。
  - まだ試作検証待ちの項目のみ、各記事末に「実機で詰める点」として正直に残す。
  - 「組み立てて動いた」とは書かない（現状は設計フェーズ）。完成イメージの設計記録として書く。
