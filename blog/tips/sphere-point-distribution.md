> 球面に点をできるだけ均等に並べたい。代表的なのが **Fibonacci球面（点ベース）** と **ゴールドバーグ多面体（面ベース）**。どちらが優れているかではなく、**どこに何を使うか**という話をします。実際、いま作っている球体LEDガジェットでは、外殻とコアで**この2つを使い分けています**。

## 1. 「球面に均等」に厳密解はない

緯度経度グリッド（地球儀の方眼）で点を打つと、極に近づくほど密集します。そして「球面に N 個を完全に等間隔」という配置には、**一般に厳密解がありません**（N=正多面体の頂点数などを除く）。なので実務では「用途に合った近似」を選びます。

ここでは2つの王道を比べます。

## 2. Fibonacci球面（らせん配置）

黄金角（≈137.5°）ずつ回しながら、z 座標を等間隔に刻む——たったこれだけで、点が球面にほぼ均等に散ります。

```python
import numpy as np

def fibonacci_sphere(n, r=1.0):
    i  = np.arange(n)
    ga = np.pi * (3.0 - np.sqrt(5.0))      # 黄金角 ≈ 137.5°
    z  = 1.0 - 2.0 * (i + 0.5) / n         # z を [-1, 1) に等間隔
    rad = np.sqrt(1.0 - z * z)             # その緯度での半径
    th  = ga * i                           # 黄金角ずつ回す
    return r * np.column_stack([np.cos(th) * rad, np.sin(th) * rad, z])
```

- **長所**：**任意の N** を一発で生成できる／実装が数行／点間隔がなめらか／密度（N）の調整が一瞬
- **短所**：得られるのは**点だけ**（面・辺・隣接の概念がない）／対称性は弱い／**極の周辺に"らせんの規則性"が出やすい**

最後の「極の規則性」は地味に効きます。球を**回して見せる**用途だと、規則的な極が"目印"になって回転が見えてしまう。後述しますが、これが外殻に Fibonacci を使わなかった理由の一つです。

## 3. ゴールドバーグ多面体（面ベース）

ほぼ六角形＋12個の五角形で球面を「面」で覆う多面体です。面の中心に点を置きます。

- **長所**：**面・辺・隣接**が定義できる／**5回対称**などの強い対称性／六角形が主体で見た目が整う
- **短所**：任意 N は不可（面数は T=m² の離散値）／生成は3ステップでやや重い

> 生成方法（正二十面体→測地線細分→双対）の詳細は別記事 [ゴールドバーグ多面体を numpy で生成する](https://zenn.dev/sastle/articles/4156ddb961e4da) に。

## 4. 比較：どこに何を使うか

| | Fibonacci球面 | Goldberg多面体 |
| --- | --- | --- |
| 単位 | 点 | 面（隣接・辺あり） |
| 任意の個数 N | ◎ 一発 | ✕（T=m² の離散値） |
| 密度調整 | ◎ N を変えるだけ | △ m を変える（飛び飛び） |
| 対称性 | 弱い | 強い（5回対称） |
| 実装 | 数行 | 3ステップ |
| 極の規則性 | 出やすい | 出にくい |
| 向く用途 | 点を散らすだけでよい所 | 面・隣接・対称分割が要る所 |

ざっくり言うと、**「隣接や対称性が要るか？」**が分かれ目です。

## 5. このプロジェクトでの使い分け

同じ球体ガジェット「Isolation Sphere」の中で、外殻とコアに別々の手法を使っています。

### 外殻（LEDシェル）→ Goldberg多面体

外殻は **800個のLEDを面の中心に置き**、それを**一筆書きで配線**し、さらに**10個の交換式カセットに分割**します。ここでは：

- 面・辺・**隣接**が要る（配線の一筆書き、カセット境界）
- そして決定打が **「10個の合同なカセットに分割できる」** こと。Goldbergの5回対称のおかげで、北5枚＝72°回転・南5枚＝赤道反転で**全部が合同**になり、**FPCを1種類のGerberで10枚**作れる
- おまけに**回しても極が目立たない**（表示球＝アイソレーションに向く）

Fibonacci球面では、合同分割も隣接定義もできません。だから外殻は Goldberg 一択でした。

### inner-core（内部コア）→ Fibonacci球面

inner-core は、mother-ring に接続した基板と電池を覆う**カバー**です。役割は2つ：

1. **カセット固定ネジを受けるパイプの土台**になる
2. **メッシュ化して内部の熱を外へ逃がす**（放熱）

ここでは面の隣接も合同分割も要りません。必要なのは「**メッシュの密度を自由に調整**できること」と「**外殻の Goldberg と見た目の印象を変える**こと」。それなら **Fibonacci球面が最適**でした（N を変えるだけで粗密が決まり、らせん模様が Goldberg のハニカムと好対照になる）。

#### メッシュボールの作り方 —— Fibonacci種 × 球面Voronoi × メタボール

inner-core の「網目の球」は、実は **§6 の実験（Voronoi分割）がそのまま製法**になっています。Fibonacci の点に直接メタボールを置くのではなく、**Fibonacci点を"種"にして球面 Voronoi を作り、そのリブ（セルの辺）にメタボールを並べる**のがミソです。手順（Blender + scipy）：

1. **Fibonacci格子で種点を生成**（黄金比で N 点、例：400）
2. その種点で**球面 Voronoi 分割**（`scipy.spatial.SphericalVoronoi`）→ ほぼ六角＋少数の五角のセル。その**辺（リブ）の網**が骨格になる
3. **リブにメタボールを並べる**：
   - Voronoi 頂点（リブの交差点）にボール
   - 各エッジは**大円弧（slerp）**に沿って内分し、メタボールを連ねる
   - エッジを**内側へ少したわませ**（数 %）、リブが球心方向へ丸まる有機的な形に
   - エッジ中央ほど半径・stiffness を変えて、リブらしい肉付きに
4. メタボールの**解像度（resolution）としきい値（threshold）**で、網目の精細さと肉の太さを調整
5. メッシュ化 → STL（mother-ring 接続部・ネジ受けパイプ・配線開口は別形状で足す）

段階が **点配置（Fibonacci）→ セル化（Voronoi）→ 肉付け（メタボール）** と分かれているので、**種点の数で網目の粗密**、**メタボールのパラメータでリブの太さ**を独立に振れます。放熱（穴を大きく）と剛性（肉を太く）を別々に追い込めるわけです。Goldbergのハニカムとはまったく違う、ぬるっとした網目になるのも狙いどおり。

> 面白いのは、§6で「極が目立たない自然な配置」を探して行き着いた Voronoi が、**そのまま inner-core の製法として生きている**こと。外殻は対称性を求めて Goldberg へ、コアは有機的な網を求めて Fibonacci種の Voronoi＋メタボールへ——同じ探索から、用途の違う2つの答えが出ました。

（実物は、序章ポータルのアボガドコア断面写真で、外殻の内側に見える網目ドームがこれです。）

> つまり同じ「球面均等配置」でも、**外殻＝隣接と合同分割が要る→Goldberg**、**コア＝密度調整と意匠が要る→Fibonacci種のVoronoi＋メタボール**。要件が選ばせてくれます。

## 6. ここに至るまで —— 試した実験的手法

Goldberg にたどり着く前、配置手法をいろいろ実験していました（[2023年の検討記事](https://tajmahal0707.hatenablog.com/entry/2023/06/08/074602)）。

1. **一般化螺旋（generalized spiral）** — 解析的にらせん配置。だが**極が規則的で、回すと目印になって見えてしまう**課題（Fibonacci も仲間なので同じ弱点）。
2. **粒子シミュレーション（球充填）** — Unityの剛体で600個のボールを球面にぶつけながら密に詰める。**極が分からないランダム配置**は得られたが、半径調整が要る。
3. **ボロノイ分割** — その点群を Blender でボロノイ分割すると、**ほとんど六角形＋一部だけ五角形**の自然な配置に。

https://youtu.be/Au8QosJG8wA

*▲ 実験的なボール配置の例（自身のチャンネル「A method of finely arranging 600 spheres on a spherical surface」）。球面に600個のボールをぶつけ合いながら密に詰める粒子シミュレーション。*

この「六角形だらけ＋少数の五角形」という到達点は、まさに**ゴールドバーグ多面体そのもの**。実験で手探りした配置を、**解析的・対称的に・合同分割可能な形で**与えてくれるのが Goldberg だった——という流れで、最終的に外殻は Goldberg に落ち着きました。

### 別解：正多面体（ドデカヘドロン）×XIAO版

「面で覆う」をもっと振り切ると、**正十二面体（ドデカヘドロン）**という手もあります。面は **12個の合同な正五角形だけ**。これを FPC ではなく**通常のリジッド基板**で作れば、12枚すべて同一基板＝**さらにコストが下がる**。各面はパネル化し、面の上に Voronoi セルのドームを載せます（前述の Voronoi がここでも効く）。リジッド基板だと内部スペースが小さくなるので、MCU も小型の XIAO（モニタなし）で済む——という割り切りです。

> ただしこれは Goldberg×ESP32-S3 の本流とは構成が違う**派生ライン（別企画）**。「面の数を絞って合同パネルでコストを取りに行く」方向の例として挙げておきます。詳細はいずれ別記事で。
