# 機能別 小記事トラック（Zenn 主軸）

決定版本編（`../00`〜`../06`）とは別トラックの、**機能・技術ごとの単発小記事**置き場。
読まれ方が違う（通読ではなく**検索でピンポイント**）ため、媒体も分ける。

## トラックの考え方（案A: noteポータル + Zenn）

技術コンテンツは**すべて Zenn**。note は物語ポータル(00)1枚に専念。

| | ポータル(`../00`) | 本編(`../01-06`) | 小話（このフォルダ） |
| --- | --- | --- | --- |
| 媒体 | **note**（物語） | **Zenn Book**（1冊） | **Zenn 単発記事** |
| 読み方 | 入口・目次・物語 | 通して読む | 検索で1個だけ |
| コード | 載せない | 図・コードOK | 技術レシピ / 検討ログ |

- note ポータル → 本編Book・小話へリンク。各Zenn記事 → ポータルへ戻る。

### 記事間リンクの規約（ハブ&スポーク）

- **序章(`../00-overview.md`) = note 物語ポータル**: 「全損トラウマ → 最終形3原則」を一度だけ書く。
- **小話 = Zenn スポーク**: 冒頭で背景を再説明しない。**末尾に共通フッターでポータルへ戻すリンク**を必ず置く。
  - 共通フッター形:
    > *…シリーズの小記事です。プロジェクト全体像と「なぜ作り直すのか（全損トラウマ）」は **序章（ポータル）** を参照。*
    > *関連: 〇〇 ／ △△。*
- **逆向き**: 序章 §6（目次）から各 Zenn 記事へリンク。
- 公開後は `序章` を **note ポータルの実URL**に、関連リンクを **Zenn の実URL**に置換。
- Zenn 内でも使い分け:
  - **Article（記事）** = 完成した技術レシピ
  - **Scrap（スクラップ）** = 結論未確定の検討ログ（更新しながら育てる）
