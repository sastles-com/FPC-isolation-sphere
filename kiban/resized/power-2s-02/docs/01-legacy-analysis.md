## Scope

旧版 power-2S (50×40 mm, 2 層) の回路・ネット構成の記録。**新基板 (power-2s-02) の回路リファレンス (正)** として使う。
解析は 2026-08-10 に `kicad-cli sch export netlist` の出力から行った。

## 1. システム全体像

```text
USB充電器 ──> J14 "CHARGE" ──POWER──> D1(ショットキー) ──CHARGE──> [U3 IP2326モジュール VIN]
                                                                        │ B+ ── P+ ネット
                                                                        │ BM ── BM ネット (セル中点直結)
                                                                        │ B− ── PGND
2S LiPo セル ──> J5/J6 ──B+/BM/B−──> [U2 XR-2S-30A BMS ※オフボード] ──P+/P−──> P+ / PGND
P+ ──FB1──> VIN ──> [U5 MP1584モジュール] ──> VOUT (5V)
VOUT ──> [Q2 DMG3415 P-FET] ──> VOUT_SWITCHED ──> J9 "OUTPUT"
              ↑ GATE
        [U1 MAX16054 プッシュボタンON/OFFラッチ]  (電源検出は POWER ネット)
```

ポイント:

- **充放電電流は必ず BMS (U2) の FET を通る** (U3 の B+/B− は保護後の P+/PGND に接続)
- **BM (バランス端子) だけは BMS を経由せずセル中点へ直結** — 新基板でも必ず踏襲
- U2 はフットプリント無し (基板非実装、ワイヤ接続)。回路図に結線記録として残す方式も踏襲する

## 4. コネクタ: legacy 11 個 → 新基板は最小構成へ削減 (2026-08-10 決定)

40×40 ではコネクタ面積が支配的になるため、**最小構成 (4〜5 個) に削減**し、デバッグ口はテストポイントで代用する。

### 新基板のコネクタ構成 (確定方針)

**電源の主インターフェースは 6p 2.54mm ヘッダ 2 個** (2P 版の CN5/CN6、legacy の J7/J8 に相当) で、
**基板の左右端・同一 Y・対向に配置する** ([`docs/04`](04-layout-thermal.md) §3.1)。
6p のうち複数ピンを電源に割り当てて電流容量を稼ぐ流儀を踏襲する。

| Ref (新) | 用途 | 主な信号 | 由来 |
| --- | --- | --- | --- |
| **CN6 (VIN 6p)** | 入力側インターフェース | GND / 充電入力 / P+ / BM | legacy J8、2P 版 CN6 |
| **CN5 (VOUT 6p)** | 出力側インターフェース | GND×2 / 5V×2 ほか | legacy J7、2P 版 CN5 |
| セル 1 | B+ / BM | 2p | legacy J5 |
| セル 2 | BM / B− | 2p | legacy J6 |
| BMS 戻り | P+ / P−(PGND) | 2p | legacy J1/J2 を 1 個に統合 |

- **Type-C レセプタクルは載せない** (充電入力はコネクタのみ、[`docs/02`](02-ip2326-module.md))
- セル 1 / セル 2 / BMS 戻りを 1 個の多極コネクタに統合するかは型番選定時に判断 (§6 Q1)
- 6p ヘッダ 2 個の**ピン割り当ての確定は未了** (§6 Q3)

### 廃止する legacy コネクタ

| Ref | 名称 | 廃止理由 |
| --- | --- | --- |
| J1, J2 | BATTERY 3p ×2 | 重複。BMS 配線用に 1 個へ統合 |
| J3 | BATTERY 2p (VIN 直タップ) | 用途不明・不要 |
| J4 | DIRECT (FET 迂回 5V) | **EN 制御方式では FET が無いため概念自体が消滅** |
| J9 | OUTPUT 2p | CN5 (6p) に統合 |
| J11 | OUT (ラッチ状態) | テストポイントで代用 |
| J12 | CLR (強制オフ) | **強制オフ端子は設けない方針** ([`docs/06`](06-power-switch.md)) |
| J14 | CHARGE 2p | CN6 (6p) に統合 |

## 5. 新基板で廃止されるネット

EN 制御方式への移行 ([`docs/06`](06-power-switch.md)) により、§3 のネット表から以下が消える:

| ネット | 廃止理由 |
| --- | --- |
| `VOUT_SWITCHED` | 直列 P-FET が無くなり、VOUT 自体を EN で断続するため |
| `GATE` | P-FET のゲート駆動が不要 |
| `CLR` | 強制オフ端子を設けない |
| `OUT` | MAX16054 のラッチ状態出力が不要 |

新規に必要なネット: ラッチ回路の内部ノード、**降圧 IC の EN**、**LED 駆動**。
(ESP32 ソフト電源断はペンディングのため、ラッチのオフ側ノードにパッドを 1 個予約するだけ — [`docs/06`](06-power-switch.md))

## 6. Open questions

- Q1: セル/BMS 系コネクタの型番確定 (JST PH 系か、より小型か)。多極 1 個に統合するか
- Q2: MAX16054 のプッシュボタン結線の詳細 — **参考情報としてのみ** (方式が変わったため踏襲はしない)
- Q3: **CN5 / CN6 (6p 2.54mm) のピン割り当ての確定** — legacy J7/J8 と 2P 版 CN5/CN6 で内容が違うため、
  2S 版として何を通すか (充電入力 / P+ / BM / 5V / GND の配分と、電流容量のための重複ピン数) を決める必要がある
