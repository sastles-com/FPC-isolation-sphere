## 1. 確定事項 (2026-08-10)

<confirmed>
- **IC: IP2326** (Injoinic / 英集芯)。5V 入力から 2S (8.4 V) へ**昇圧充電**
- **2S 構成** — モジュールの「3S 時は抵抗除去」は該当しない (抵抗実装状態が正)
- **BM (セル中点) を必ず配線** — バランス端子は **BMS を経由せずセル中点へ直結** (legacy 踏襲、Hard Rule)
- **Type-C レセプタクルは載せない** — 充電入力は**コネクタのみ** (南極の磁気端子 → AWG26×2 → 本基板)。
  したがって **CC 抵抗 (5.1 kΩ×2) や Type-C 関連部品は不要**
- **設計の根拠: データシート標準アプリケーション回路 + 自前計算**。既製モジュール実物の定数実測は行わない
- **保護機能は使わない** — 過充放電/過電流は XR-2S-30A の役割 (Hard Rule)
</confirmed>

### 既製モジュールの実測情報 (参考、写真から確認済み)

- 主 IC 刻印 **IP2326** (QFN パッケージ)
- パワーインダクタ刻印 **2R2 = 2.2 µH** (シールドタイプ、~5×5 mm)
- 設定パッド: **NTC / ISET / ROT / VSET / RUV / ROV** — 充電電流・セル数・保護閾値が外付け抵抗で設定される方式
- 端子: VIN / GND (Type-C 側) と B+ / BM / B− (バッテリ側)

### legacy 基板での使われ方 ([`docs/01`](01-legacy-analysis.md))

- VIN ← 充電入力 (D1 ショットキー後)。モジュールの Type-C は使わず VIN 穴給電だった
- B+ → P+ (BMS 保護後)、B− → PGND、**BM → セル中点直結**

## 3. 新基板への実装指針

- 昇圧充電のスイッチング電流ループ (VIN → L → SW → 整流 → VBAT) を**最小面積**でまとめる ([`docs/04`](04-layout-thermal.md))
- インダクタは **2.2 µH / 飽和電流 ≥ 4 A / シールド品**を LCSC から選定
- IP2326 は発熱源。**露出パッド直下にサーマルビア → 内層/Bottom のベタ GND**へ逃がす
- 充電入力の逆流防止ショットキー (legacy D1、SS34 相当) は踏襲
- 充電電流は入力側 ~3 A。**コネクタと配線 (AWG26×2) の許容電流を確認** — 親 docs/03-power-charging.md Q41 で
  「AWG26 の安全電流 ~2 A でギリギリ」と指摘されている。充電電流を絞る必要があるか要検討 (§4 Q4)
