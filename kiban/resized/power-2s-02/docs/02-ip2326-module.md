## 1. 確認済みの事実 (verified)

### モジュール仕様 (商品情報・実物写真より)

- USB Type-C 入力 (5V)、**15 W 級**の 2S/3S リチウム昇圧充電モジュール
- 主 IC: **IP2326** (Injoinic / 英集芯)。QFN パッケージ、刻印 "IP2326" 確認済み
- パワーインダクタ: 刻印 **2R2 = 2.2 µH** (シールドタイプ、~5×5 mm)
- 端子: **VIN / GND** (Type-C 側) と **B+ / BM / B− / (NTC, VSET, ISET, RUV/ROV パッド)** (バッテリ側)
- **2S/3S 切替**: 基板上の抵抗 1 個。「3S にするときは抵抗を除去」→ **本プロジェクトは 2S なので抵抗実装状態が正**
- シルクに NTC / ISET / ROT / VSET / RUV / ROV の設定パッドあり → 充電電流・セル数・保護閾値が外付け抵抗で設定される方式

### legacy 基板での使われ方 (docs/01 より)

- VIN ← 充電入力 (D1 ショットキー後)。モジュールの Type-C は使わず VIN 穴給電だった
- B+ → P+ (BMS 保護後)、B− → PGND、**BM → セル中点直結**
- 2S 構成、バランス (BM) 結線あり

## 3. リバースエンジニアリング手順 (実物モジュールがある場合)

1. モジュール表裏の高解像度写真を撮る (ユーザー依頼)
2. 各チップ部品の刻印/実測値を記録 (抵抗はテスタ、コンデンサは外して LCR が確実だが、まずは刻印)
3. データシートの標準回路と突き合わせ、モジュール固有の定数 (ISET・セル数設定・保護閾値) を特定
4. 特定した回路を `docs/02` 本ファイルの「確認済み」欄へ追記してから KiCad 作図

## 4. 新基板への実装指針

- 昇圧充電のスイッチング電流ループ (VIN→L→SW→整流→VBAT) を**最小面積**でまとめる (docs/04 のゾーニング参照)
- インダクタはモジュール同等品 (2.2 µH, 飽和電流 ≥ 4 A 目安、シールド品) を LCSC から選定
- IP2326 は発熱源。**露出パッド直下にサーマルビア → 内層/裏面ベタ**へ逃がす
- 充電入力の逆流防止 D1 (ショットキー) は legacy 踏襲で維持
- Type-C レセプタクルのオンボード化は Open Question (docs/01 Q2)
