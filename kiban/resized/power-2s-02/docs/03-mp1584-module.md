## Scope

既製品 MP1584EN ミニ降圧モジュール (~22×17 mm、トリマ調整式) の回路を新基板へディスクリート実装するための設計指針。
**出力はトリマを廃止し固定 5V** にする (CLAUDE.md Hard Rules)。

## 1. 確認済みの事実 (verified)

### モジュール仕様 (商品情報・実物写真より)

- 主 IC: **MP1584EN** (MPS、SOIC-8)。入力 4.5〜28 V / 出力 0.8〜20 V (トリマ調整) / 最大 3 A 級
- パワーインダクタ: 刻印 **4R7 = 4.7 µH**
- 整流ダイオード: 刻印 **SS34** (3A ショットキー) → **非同期整流** (キャッチダイオード方式)
- 出力電圧は半固定抵抗 (トリマ) で調整 (時計回りで降圧) → **新基板では固定抵抗分圧に置換**
- 端子: Input−/Input+/Output+/Output− の 4 極 (コーナー 2 穴ずつ)

### legacy 基板での使われ方 (docs/01 より)

- IN+ ← VIN ネット (P+ から FB1 フェライトビーズ経由、C1 100µF タンタル + C3 22µF + C2 0.1µF)
- OUT+ → VOUT ネット (C7 100µF タンタル + C5/C6 22µF + C4 0.1µF) → MAX16054/FET スイッチへ
- 入力は 2S バッテリ (6.0〜8.4 V) なので降圧比は小さく熱的には楽

## 3. 設計指針

- **固定 5V**: FB 分圧は 1% 精度の抵抗を使用。トリマ禁止
- 非同期整流 (SS34 相当のショットキー) はモジュール踏襲でよいが、LCSC の SS34/SS36 系から選定
- インダクタ 4.7 µH / 飽和電流 ≥ 4 A / シールド品
- 入出力コンデンサは legacy の構成 (タンタル 100µF + セラ 22µF + 0.1µF) を踏襲しつつ、セラミックの DC バイアス特性 (0805 22µF は 5V 印加で実効容量が大きく減る) に注意して必要なら並列数を増やす
- **発熱**: 2S→5V/3A 時の損失見積りを計算し (効率 ~90% 想定で 1.5 W 級)、IC 下・ダイオード周辺に銅箔面積とサーマルビアを確保 (docs/04)
- スイッチングノード (SW) は面積最小・内層 GND で直下シールド

## 4. 負荷要件の確認 (ブロッカー)

球体 LED 側 (800× WS2812-2020) の 5V 消費電流バジェットを親プロジェクトから取得すること。
**MP1584 は 3 A が上限**。それを超える要件なら IC 変更が必要 (`kiban/power-TPS61088-1S/` で検討中の TPS61088 系など) — **ユーザーと要相談**。
親プロジェクト側にも「全白禁止 + 輝度上限運用」の記載あり (ルート CLAUDE.md §2.6)。
