## Scope

モーメンタリボタンで 5V 出力をラッチ ON/OFF する回路の設計。

## 1. 確定事項 (2026-08-10)

<confirmed>
- **方式: ディスクリートラッチ + MP1584 の EN 制御** (MAX16054 は使わない)
  - 2S 電圧 (6.0〜8.4 V) で直接動作する 2 石ソフトラッチを組み、降圧 IC の EN を駆動する
  - **直列パス FET は置かない** — 負荷電流 (最大 3 A) は素子を通らない
  - オフ時は降圧 IC 自体が停止するので、コンバータの静止電流も消える
- **付帯要件 (実装する)**:
  - **ESP32 からのソフト電源断** — GPIO でラッチを落とす入力を 1 本設ける (自動スリープ用)
  - **電源状態 LED** — オン / 充電中を目視で判別できる表示
- **付帯要件 (実装しない)**:
  - 強制オフ (legacy の CLR 相当) 専用端子は設けない — ESP32 入力で代替
  - ESP32 への電源状態通知 (PWR_STATE 出力) は今回のスコープ外
</confirmed>

## 2. 却下した方式とその理由 (再提案禁止)

| 方式 | 却下理由 |
| --- | --- |
| legacy 踏襲: MAX16054@VOUT + 直列 P-FET | オフ時も MP1584 が動き続ける (常時消費)。オン時は 3 A が P-FET を通り 0.3〜0.5 W の導通損失 |
| MAX16054 + µA 級 LDO + EN 制御 | MAX16054 の VCC 上限は 5.5 V で 2S 直給電できず、LDO 追加が必要。ディスクリートラッチなら LDO 不要で同等以上 |
| スライドスイッチで EN 直結 | UX が変わる (モーメンタリでない)。球体内での配置制約 |
| ESP32 セルフホールドのみ | 電源基板が別基板のソフトに依存。ソフト死亡時に切れない |

## 3. 回路要件

| 項目 | 要求 |
| --- | --- |
| 電源電圧 | **2S 直接 (6.0〜8.4 V)**。降圧・LDO を介さない |
| 操作 | モーメンタリ押しボタン 1 個でトグル ON/OFF |
| オフ時消費電流 | **≤ 10 µA を目標** (ディスクリートラッチなら ~1 µA 級が狙える) — 目標値はユーザー未合意 (§5 Q1) |
| 出力 | 降圧 IC の **EN** を駆動。EN の絶対最大定格が VIN 未満の場合は分圧またはオープンドレイン駆動 |
| ESP32 入力 | ラッチをオフ側へ倒す入力 1 本。ESP32 が 3.3 V 系のため**レベル整合に注意** (2S 系との直結不可) |
| LED | オン表示 + 充電中表示。輝度は最小限 (常時点灯のため消費電流を抑える) |
| デバウンス | RC でチャタリング対策。押下時間と誤動作のトレードオフを定数で調整 |

## 4. 設計時の注意

- **EN の電気的仕様を先に確認する** ([`docs/03`](03-mp1584-module.md) の未確認項目)。閾値・絶対最大・内部プルの有無で駆動方法が変わる。
- **出力コンデンサの放電時間**: EN オフでも 5V がしばらく残る。即断が要るならブリーダ抵抗を検討 (常時消費とのトレードオフ)。
- **充電との独立性**: 出力オフでも IP2326 の充電は動くこと。充電ブロックは P+/PGND 側で完結しており EN 制御の対象外。
- **ESP32 入力の絶縁/レベル**: 2S 系のラッチノードへ 3.3 V ロジックを直結してはいけない。小信号 N-MOS を介す等の対策が必要。
- ボタンは球体外殻からのアクセス方法が未定 — 親プロジェクトの機構と要調整 (§5 Q3)。
