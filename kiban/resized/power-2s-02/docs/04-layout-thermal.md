## Scope

新基板 (40×40 mm, 4 層) の層構成・ゾーニング・ベタ GND・排熱・大電流パスの設計方針。

## 1. 基板仕様 (確定)

| 項目 | 値 |
| --- | --- |
| 外形 | **40 × 40 mm** |
| 層数 | **4 層** |
| **取付穴** | **四隅に M2 (Φ2.2) × 4** |
| **実装面** | **片面実装 (Top のみ)** — Bottom 全面をベタ GND 放熱面にできる。PCBA コストも安い |
| 板厚 | 1.6 mm |
| 銅箔厚 | 外層 1 oz (JLCPCB 標準)。電流計算で不足なら 2 oz を検討 (§7 Q1) |
| 表面処理 | 発注時決定 ([`docs/05`](05-jlcpcb-fab.md)) |

## 2. 層構成 (stackup)

| 層 | 割当 |
| --- | --- |
| L1 (Top) | **全部品** + 大電流パス (充電昇圧ループ / 降圧ループ) |
| L2 | **GND ベタ (切れ目なし厳守)** — スイッチングループのリターン & シールド |
| L3 | 電源プレーン (P+ / VOUT / CHARGE を分割配置) + 補助配線 |
| L4 (Bottom) | **ベタ GND + 放熱銅箔** (部品なし) |

原則:

- **L2 の GND は絶対に分断しない**。スイッチングノード直下も L2 GND で受ける
- 部品は Top のみ。Bottom は放熱と GND リターンに専念させる

## 3. ゾーニング (配置案)

```text
+--------------------------------------+
| ○                                  ○ |  ← 四隅 M2 穴
|  [充電入力コネクタ]  [IP2326]        |  ← 充電昇圧ゾーン (発熱源1)
|    D1  L(2.2µH)  Cin/Cout            |
|--------------------------------------|
|  [セル×2 / BMS 戻りコネクタ] BMライン |  ← コネクタ帯 (B+/BM/B−/P+/P−)
|--------------------------------------|
|  [MP1584] L(4.7µH) SS34  Cin/Cout    |  ← 降圧ゾーン (発熱源2)
|  [ラッチ回路 + LED]  [5V出力コネクタ] |  ← 小信号 + 出力
| ○                                  ○ |
+--------------------------------------+
```

- 発熱源 2 つ (IP2326 / MP1584+ダイオード) を**基板の対辺に離す**
- 2 つのスイッチングループを近接させない (相互干渉回避)
- コネクタは外周縁に整列。**最小構成 (4〜5 個) に削減済み**なので面積は確保しやすい
- BM ライン (バランス、電流小) は細くてよいがパック電圧が乗るため沿面確保
- ラッチ回路は 2S 電圧で動く小信号なので、スイッチングノードから離して配置

## 4. 大電流パスの設計 (必ず計算で裏取り)

| パス | 想定電流 | 備考 |
| --- | --- | --- |
| 充電: CHARGE(5V) → IP2326 → L → B+(P+) | 入力側 ~3 A (15 W / 5 V) | 昇圧入力側が最大電流 |
| 放電: P+ → MP1584 → VOUT(5V) | 5V 側 **最大 3 A**、入力側 ~2 A | 降圧なので入力電流は小 |
| 5V 出力 → コネクタ | 最大 3 A | **直列 FET は無し** (EN 制御方式のため) |

- トレース幅は IPC-2152 で温度上昇 ≤20 ℃ を目安に算出
- 3 A 級パスは **幅 ≥2 mm + ポリゴン** を基本、層間は **ビア多打ち** (Φ0.3 で ~1 A 目安 → 3 A なら 3〜4 個以上)
- **FB1 (legacy の 0603 フェライトビーズ) は定格電流不足の可能性が高い** — サイズアップ (1206/1812) か撤去を判断 (§7 Q2)

## 5. 排熱設計

- **IP2326**: 露出パッド直下に **サーマルビア 3×3 (Φ0.3、ピッチ 1.0-1.2 mm)** → L2/L4 のベタ GND へ
- **MP1584EN**: SOIC-8 の GND ピン/パッケージ下に銅箔拡張 + ビア。SS34 (SMA/SMB) はアノード側ランドを広げる
- 片面実装のため **Bottom 全面が放熱面として使える** — 発熱源の直下領域は銅箔をベタで確保
- Bottom のレジスト開口による放熱強化は、球体内での絶縁を優先して**行わない** (必要性が出たら再検討、§7 Q3)
- 密閉球体内で対流が期待できないため、**銅箔面積での拡散が主役**。
  損失見積り (充電時 ~1.5-2 W、放電時 ~1.5 W) に対し最悪ケース (充電しながら点灯) の温度上昇を試作で実測する

## 6. EMC / ノイズ

- スイッチングループ (IP2326 昇圧 / MP1584 降圧) はそれぞれ**最小ループ面積**でまとめ、直下 L2 GND でリターン
- SW ノードのポリゴンは最小限に (dv/dt 大)
- 5V 出力は WS2812 のデータ品質に影響するためリップル抑制を意識
