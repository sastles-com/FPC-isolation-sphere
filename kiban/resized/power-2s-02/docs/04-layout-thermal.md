## Scope

新基板 (40×40 mm, 4 層) の層構成・ゾーニング・ベタ GND・排熱・大電流パスの設計方針。

## 1. 基板仕様

| 項目 | 値 |
| --- | --- |
| 外形 | 40 × 40 mm (角 R は取付都合で決定、未確定) |
| 層数 | 4 層 |
| 銅箔厚 | 外層 1 oz (JLCPCB 標準)。大電流計算で不足なら外層 2 oz を検討 (JLCPCB 4層はコスト増、要確認) |
| 板厚 | 1.6 mm (標準) |
| 表面処理 | JLCPCB 標準 (HASL) or ENIG — 発注時決定 |

## 2. 層構成 (stackup)

| 層 | 割当 |
| --- | --- |
| L1 (Top) | 部品 + 大電流パス (充電昇圧ループ / 降圧ループ) |
| L2 | **GND ベタ (切れ目なし厳守)** — スイッチングループのリターン & シールド |
| L3 | 電源プレーン (P+ / VOUT / POWER を分割配置) + 補助配線 |
| L4 (Bottom) | ベタ GND 主体 + 放熱銅箔 + 必要なら小信号 |

原則:
- **L2 の GND は絶対に分断しない**。スイッチングノード直下も L2 GND で受ける
- パワー部品は片面 (Top) 実装に寄せ、Bottom は放熱面として使うのが第一候補 (JLCPCB 片面実装の方が安い)

## 3. ゾーニング (配置案)

```text
+--------------------------------------+
| [充電入力/Type-C or J14]  [IP2326]   |   ← 充電昇圧ゾーン (発熱源1)
|   D1  L(2.2µH)  Cin/Cout             |
|--------------------------------------|
| [バッテリ/BMS コネクタ群]  BM ライン |   ← コネクタ帯 (P+/BM/B±)
|--------------------------------------|
| [MP1584] L(4.7µH) SS34  Cin/Cout     |   ← 降圧ゾーン (発熱源2)
| [MAX16054 + DMG3415]  [出力コネクタ] |   ← 小信号 + 出力
+--------------------------------------+
```

- 発熱源 2 つ (IP2326 / MP1584+ダイオード) を**基板の対角または対辺に離す**
- 2 つのスイッチングループを近接させない (相互干渉回避)
- コネクタは外周縁に整列。40×40 ではコネクタ面積が支配的 → docs/01 §4 の棚卸し結果を反映
- BM ライン (バランス、電流小) は細くてよいがパック電圧が乗るため沿面確保

## 4. 大電流パスの設計 (必ず計算で裏取り)

想定電流 (作図前に要確定、docs/03 §4):

| パス | 想定電流 | 備考 |
| --- | --- | --- |
| 充電: CHARGE(5V) → IP2326 → L → B+(P+) | 入力側 ~3 A (15W/5V) | 昇圧入力側が最大電流 |
| 放電: P+ → FB1 → MP1584 → VOUT | 5V 側で最大 3 A | 入力側は ~2 A (8.4→5V) |
| VOUT → Q2 → VOUT_SWITCHED | 同上 | DMG3415 の Rds(on)/定格照合 |

- トレース幅は IPC-2152 で温度上昇 ≤20 ℃ を目安に算出 (計算スクリプトを `uv run python` で作ってよい)
- 3 A 級パスは **幅 ≥2 mm + ポリゴン** を基本、層間は **ビア多打ち** (1 ビア Φ0.3 で ~1 A 目安 → 3 A なら 3〜4 個以上)
- FB1 (0603 フェライトビーズ) の定格電流を要確認 — legacy の 0603 では 3 A に足りない可能性。**サイズアップ (1206/1812) or 削除判断が必要 (Open Question)**

## 5. 排熱設計

- IP2326: 露出パッド (あれば) 直下に **サーマルビア 3×3 (Φ0.3, ピッチ 1.0-1.2 mm)** → L2/L4 の GND ベタへ
- MP1584EN: SOIC-8 の GND ピン/パッケージ下に銅箔拡張 + ビア。SS34 (SMA/SMB) はアノード側ランドを広げる
- Bottom 面 (L4) の対応領域はレジスト開口しない (球体コア内での短絡防止を優先。開口は放熱有利だが要相談)
- 密閉球体内で対流が期待できないため、**銅箔面積での拡散が主役**。損失見積り (充電時 ~1.5-2 W、放電時 ~1-1.5 W) に対して 40×40・4 層の銅体積は十分だが、両ゾーン同時最悪 (充電しながら全点灯) の温度上昇を試作で実測すること

## 6. EMC / ノイズ

- スイッチングループ (IP2326 昇圧 / MP1584 降圧) はそれぞれ**最小ループ面積**でまとめ、直下 L2 GND でリターン
- SW ノードのポリゴンは最小限に (dv/dt 大)
- 5V 出力は LED (WS2812) のデータ品質に影響するためリップル抑制を意識 (出力コンデンサバンクは legacy 踏襲 + 必要なら増強)
